TypeScript Features Documented:

1. Mapped Types Patterns:
   - type Getters<T> = { readonly [K in keyof T]: () => T[K] }
   - type Setters<T> = { [K in keyof T]: (v: T[K]) => void }
   - type Readonly<T> = { readonly [K in keyof T]: T[K] }
   - type Flatten<T> = { [K in keyof T]: T[K] extends Array<U> ? U : T[K] }

2. Decorator Patterns:
   - @Component({ selector: 'app' })
   - @Injectable({ providedIn: 'root' })
   - @Directive({ selector: '[appHighlight]' })
   - @Deprecated('Use NewClass')

3. Generic Constraint Patterns:
   - <T extends string>
   - <T extends { x: number }>
   - <T extends string | number>
   - <T extends A & B>

4. Union/Intersection Patterns:
   - type Status = 'active' | 'inactive' | 'pending'
   - type Admin = User & { role: 'admin' }
   - type Result = Success | Failure | Pending

5. Module Patterns:
   - import { Component } from '@angular/core'
   - export class Service {}
   - export default {}

6. Async/Await Patterns:
   - async function load(): Promise<Data>
   - const result = await fetch(url)
   - Promise.all(), Promise.race()
