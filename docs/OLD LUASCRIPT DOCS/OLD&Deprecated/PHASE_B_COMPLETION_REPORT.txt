FIX #1: IMPLEMENT OBJECT POOLING (2-3 hours)
─────────────────────────────────────────────
Goal: Reuse IRNode and IRType objects instead of creating new ones

Implementation:
```javascript
class ObjectPool {
  constructor() {
    this.irNodes = [];
    this.irTypes = [];
  }
  
  getIRNode(type, data) {
    const node = this.irNodes.pop() || {};
    node.type = type;
    Object.assign(node, data);
    return node;
  }
  
  getIRType(kind, props) {
    const type = this.irTypes.pop() || {};
    type.kind = kind;
    Object.assign(type, props);
    return type;
  }
  
  clear() {
    this.irNodes = [];
    this.irTypes = [];
  }
}
```

Expected Impact: 80-90% memory reduction

FIX #2: OPTIMIZE TREE TRAVERSAL (1-2 hours)
────────────────────────────────────────────
Goal: Use in-place modifications instead of deep copies

Current (problematic):
```javascript
traverseAndTransform(ir, fn) {
  const copy = JSON.parse(JSON.stringify(ir));  // ← DEEP COPY
  return this.traverse(copy, fn);
}
```

Optimized:
```javascript
traverseInPlace(ir, fn) {
  if (!ir || typeof ir !== 'object') return ir;
  
  fn(ir);  // Modify in place
  
  for (const key in ir) {
    if (Array.isArray(ir[key])) {
      ir[key].forEach(child => this.traverseInPlace(child, fn));
    } else if (typeof ir[key] === 'object') {
      this.traverseInPlace(ir[key], fn);
    }
  }
  
  return ir;
}
```

Expected Impact: 50-70% faster processing
