# Experimental Examples

Files in this directory are aspirational or experimental. They are not part of the baseline example integration suite.

`mathematical_showcase.ls` demonstrates a future mathematical DSL direction with Unicode operators, pipeline expressions, pattern-style equations, and `x -> ...` / `x → ...` forms. The current baseline compiler does not support that full syntax. Keep it here as design material until the DSL is implemented and covered by end-to-end tests.
